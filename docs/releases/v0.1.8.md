# v0.1.8 好友聊天导出与紧凑窗口

2026-11-18

- 左侧菜单新增“好友聊天”，与“群聊聊天”分开展示。好友名称优先使用本地备注，其次昵称；支持搜索好友名。
- 好友聊天支持浏览、加载更早消息、文字和卡片搜索、消息整行勾选，以及按日期或已勾选消息导出 HTML，保留本地图片与大图查看。
- 好友分类支持批量合并或分开导出。批量窗口只列出当前分类的会话，好友与群聊分别记住上次选择和导出方式。
- 切换左侧分类会清空当前聊天、搜索和消息勾选；在同一聊天中搜索、清空搜索或加载更早消息仍保留已勾选内容。
- 默认窗口从1380×900调整为1100×720，宽高约为原来的八成；最小尺寸仍为960×640。主要搜索和导出操作保持单行显示。
- 个人消息保留原文，不删除形似群聊发送者前缀的文字。

列表来自电脑上的可见会话，不是完整通讯录；已知公众号、系统服务及企业微信会话不列入好友分类。应用继续只读取本机已有数据，不联网补全消息或图片。导出格式为含图片的单文件 HTML，结束日期包含当天全天。

下载 `ChatKeep.exe` 后可直接运行，无需安装 Python 或 .NET。附件另含 `SHA256SUMS.txt` 和 `ThirdPartyLicenses.zip`。本次发布程序与已交付的紧凑窗口测试版逐字节一致，旧版及其数据可继续保留。

已通过50项读取和导出测试及封装模块回归，包含好友分类、发送者、日期、图片隔离、勾选和批量导出；通过WPF布局、菜单切换、工具栏、图片查看和导出窗口检查，以及无外部Python/.NET环境下的独立启动验证。以上本轮检查使用合成数据，不代表已覆盖所有真实账号或微信版本。
