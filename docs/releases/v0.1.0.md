# 聊存 ChatKeep v0.1.0

首个可试用版本，面向 Windows x64 的本地微信聊天记录浏览与导出工具。

## 下载与使用

下载 **ChatKeep.exe**，放在可写文件夹中双击运行。已内置所需运行环境，无需安装 Python 或 .NET。

保持微信登录，点击“连接微信” → 选择群聊 → “导出聊天记录” → 选择日期 → 确认导出。结束日期包含当天全天；也可勾选消息后导出。

## 本版功能

- 三栏桌面界面，支持搜索群聊与分页浏览消息。
- 按日期范围或手动勾选导出单个群聊。
- 文字和本地可解码图片保存为单文件 HTML。
- 图片优先使用本地原件，缺失资源保留占位说明。
- 使用只读方式读取本地微信数据，不要求重启微信。

## 兼容与限制

已在 Windows 11、微信 4.1.15.13 上完成连接、消息读取、图片解码和 HTML 导出验证，其他环境尚未充分测试。

当前只提供群聊和 HTML 导出；部分特殊图片格式以及语音、视频、表情和卡片内容暂未完整支持。不提供后台自动同步。

首次连接会自动创建 `private` 缓存目录；默认导出到 `exports`。`private/cache` 包含本机解密副本，请按聊天记录保管。应用本身不上传聊天数据。

校验文件见同一 Release 的 `SHA256SUMS.txt`。

第三方组件许可证附于 `ThirdPartyLicenses.zip`。
