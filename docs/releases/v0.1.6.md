# v0.1.6 界面优化、群内搜索与选择导出

- 新增群内消息搜索：输入关键词后按回车，搜索当前群聊全部本地文字和可解析卡片文本，可继续加载更早的匹配消息。点击×、按Esc或清空输入返回正常浏览；不识别图片内文字。
- 消息顶部改为单行工具区：群名、会话搜索、选择、导出 HTML。最小窗口为960×640，小窗口下列表和搜索框适当收窄，长群名省略并可悬停查看全名。
- 点击“选择”进入勾选模式，按钮显示绿色“选择中”，已选数量仅在右下角显示。勾选后点击“导出 HTML”直接选择保存位置；未勾选时不可导出。再次点击“选择中”退出并清空选择。
- 搜索、清空搜索和加载更早消息会保留本群已勾选消息，直接导出包含当前画面外的选择。切换群聊或重新连接时清空选择。普通浏览模式仍可按日期导出，结束日期包含当天全天。
- 群聊整行选中效果改为圆角浅绿色，悬停为浅灰色；搜索框改为圆角灰底并加入放大镜图标。
- 群聊列表和消息区采用灰色圆角细滚动条，长度随可见内容比例调整，保留滚轮、拖动、轨道翻页和键盘操作；内容全部可见时自动隐藏。

保留多群批量合并/分开导出、本地清晰图片、大图查看、卡片与引用识别。当前导出格式为单文件 HTML。应用只读取本机已有数据，不联网补全消息或图片。

下载 `ChatKeep.exe` 后可直接运行，无需安装 Python 或 .NET。附件另含 `SHA256SUMS.txt` 和 `ThirdPartyLicenses.zip`。

已通过44项读取与导出测试、消息布局和工具栏检查，以及无外部Python/.NET环境下的独立启动验证。
