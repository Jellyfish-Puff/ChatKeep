# 聊存 ChatKeep v0.1.1

本版让工作群中转发的公众号文章、围绕文章的引用回复，以及常见卡片消息在浏览和 HTML 导出中保留可读信息。

## 本版更新

- **公众号文章**：读取本地消息中已有的标题、链接、公众号名称和摘要；普通网页分享保留本地标题与网址。
- **文章关联**：导出时为可确认的同篇文章标注相同的文件内编号（如 A001），引用中的文章和直接粘贴的公众号网址也参与编号。保留原始链接，不凭标题相同合并。
- **引用回复**：保留回复正文、被引用消息的发送者和可解析内容，方便后续阅读和分析。
- **消息分类**：区分文件、红包、转账、拍一拍、小程序、视频号、合并聊天记录、音乐分享及撤回消息。拍一拍尽量还原成员名称与后缀；文件显示文件名。
- **复制与导出**：界面文字和长网址可选中复制、自动换行；导出 HTML 中的有效 HTTP/HTTPS 链接可手动打开。
- **异常处理**：卡片损坏、字段缺失或格式暂未支持时保留说明，不影响其他消息；增加 XML、引用层级和 HTML 转义检查。

## 下载与使用

下载 **ChatKeep.exe**，放入可写文件夹后双击运行，无需安装 Python 或 .NET。保持微信登录，点击“连接微信”，选择群聊，再按日期或勾选消息导出。

升级前可退出旧版后替换 EXE，也可将新版放到另一个文件夹运行。缓存和导出目录跟随 EXE 所在目录；放到新文件夹后需要重新连接微信。

同一 Release 提供 **SHA256SUMS.txt** 校验文件与 **ThirdPartyLicenses.zip** 第三方组件许可证。

## 验证与限制

- 14 项自动化测试通过，覆盖原有导出回归及新增的压缩卡片、引用回复、文章匹配、分类与安全处理。
- 本机已有缓存抽样 400 条消息，30 处文章信息（含引用）均读取到本地标题。封装后的解析模块通过相同测试，独立 EXE 启动与合成界面预览通过。
- 验证环境为 Windows 11、微信 4.1.15.13；其他微信版本和特殊卡片仍需适配。
- 全程读取电脑端已有数据，不请求公众号网页、历史文章、正文或封面，不依赖屏幕操作。缺失的标题不会联网补全。
- 临时链接缺少完整文章标识时保守匹配，可能获得不同编号；编号仅在当前导出文件内有效。
- 红包和转账仅展示本地消息提示，不推断实时领取或交易状态；小程序、视频号、合并聊天记录和文件不展开内部内容。语音、视频等原有限制保留。

`private/cache` 为本机解密聊天副本，默认导出位于 `exports`，请按聊天记录保管。应用本身不上传聊天数据。
