# 聊存 ChatKeep v0.1.4

本版改进本地图片的清晰度与查看体验，并修复部分群聊打开后闪退的问题。包含此前本地0.1.2、0.1.3版本的改进。

## 本版更新

- **优先清晰图片**：比较消息关联的本地文件，按实际像素选择可读取的最佳版本；支持常见图片及可识别的微信WXGF/HEVC图片，转换时保留原像素尺寸。
- **明确缩略图**：仅有缩略图时显示来源与尺寸，不再提供“查看大图”按钮。存在其他候选但读取失败时也会说明；后来下载到更清晰图片后，重新加载或导出会再次检查本地资源。
- **大图缩放**：默认适应窗口，支持滚轮缩放、＋／－、百分比、100%原始尺寸、拖动及滚动条查看细节。Ctrl＋0适应窗口、Ctrl＋1原始尺寸、Ctrl＋加减号缩放、Esc关闭。
- **HTML图片查看**：图片仍内嵌在单个HTML文件中，支持点击切换原始尺寸。应用内缩放只影响显示，不缩小导出图片。
- **群聊闪退修复**：修复部分含“1️⃣、2️⃣”等数字表情的消息在自动换行时触发界面崩溃的问题，保留原始文字及复制功能。
- **解码容错**：特殊图片格式在独立读取子进程中解码，增加超时和尺寸限制，读取失败时尝试其他可用候选。

## 下载与使用

下载 **ChatKeep.exe**，放入可写文件夹后双击运行，无需安装Python、.NET或FFmpeg。保持微信登录，点击“连接微信”，选择群聊，再按日期或勾选消息导出。

升级时退出旧版后替换EXE即可，也可以将新版放入独立文件夹。缓存及默认导出目录跟随EXE所在位置；放入新文件夹后需要重新连接。应用不会自动删除已有缓存或导出记录。

本版EXE约134.2 MiB，包含图片解码组件。缩放功能本身相较0.1.3仅增加9 KiB，未引入额外界面依赖。同一Release提供 **SHA256SUMS.txt** 和 **ThirdPartyLicenses.zip**。

## 验证与限制

- 29项自动化测试通过，覆盖数据库认证、分页、卡片、导出以及本地图片匹配、像素保持、损坏回退和解码子进程超时。
- 100条合成混合消息及目标群最近300条本地缓存通过6轮界面回归；横图、长截图和小图通过大图窗口缩放、适应、平移及源图保持检查。封装解码组件与独立EXE启动检查通过。
- 图片处理仅访问电脑端已有的消息与关联文件，不联网补充原图，不依赖微信屏幕操作。未下载的原图可能无法获取，放大缩略图也不会增加真实细节。
- 复杂透明或动画图片暂保留可识别的静态首帧并标注。语音、视频等仍不播放或导出媒体文件；已有卡片识别能力保留。
- 验证环境为Windows 11、微信4.1.15.13，其他版本仍需适配。

`private/cache`包含本机解密聊天副本，默认导出位于`exports`，请按聊天记录保管。应用本身不上传聊天数据。
