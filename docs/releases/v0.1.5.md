# v0.1.5 多群批量导出

支持一次选择多个群聊，使用相同日期范围导出工作消息，可合并保存或按群分别保存。

[下载 Windows 单文件版](https://github.com/Jellyfish-Puff/ChatKeep/releases/tag/v0.1.5)。下载 `ChatKeep.exe` 即可运行，无需安装 Python 或 .NET。

- 中间群聊列表顶部新增“批量导出”；连接成功后即可使用，无需先打开一个群聊。
- 导出窗口支持搜索、复选框选择群聊及已选数量；切换搜索结果保留勾选。
- 开始日期和结束日期统一应用于所选群聊，结束日期包含当天全天。
- 可选择合并为一个 HTML（群聊目录、按群聊分区），或每个群聊一个 HTML。
- 图片、发送者、时间、文字、卡片、引用及原始图片尺寸切换沿用现有导出能力。合并文件内的文章编号跨群共用，独立文件内单独编号。
- 每次导出新建批次文件夹，同名群聊的文件使用序号区分，不覆盖旧文件。
- 显示逐群进度，结果窗口逐群报告成功、无消息和失败，以及图片缩略图和缺失数量；失败的群不会阻止其他群处理。
- 群聊选择和导出方式保存在 EXE 旁的 `private/batch-export.json`，仅保存群标识和方式，不保存正文或密钥；取消设置窗口不会修改上次选择。不存在于当前群列表的旧选项不会自动加入本次导出。
- 原有单群导出和逐条勾选功能保留。仍只读取电脑已有数据，不联网补全，也不做应用内 AI 分析。

验证：37 项自动测试通过；合成消息界面、批量窗口与进度通信、封装图片解码，以及无外部 Python/.NET 路径下的独立启动检查通过。用户已完成实际使用测试并确认正常。

首次使用需连接微信，程序在 EXE 所在目录创建自己的缓存和导出文件夹。更换 EXE 所在文件夹时，缓存与设置不会自动迁移。
