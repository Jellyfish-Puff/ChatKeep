# v0.1.7 消息整行选择与导出窗口

- 选择模式下，已勾选消息泡显示绿色圆角边框；取消勾选后去除边框，消息尺寸和位置保持稳定。
- 点击消息文字、图片或所在行的空白区域可切换勾选。复选框保留原生操作，“查看大图”按钮继续打开图片；普通浏览模式可选择并复制文字。
- 顶部“导出 HTML”改为“导出”。普通浏览和选择模式统一进入导出设置窗口，包含群名、日期范围、导出内容、格式、已加载/已勾选数量和底部操作按钮。
- “选择”和“导出”按钮统一为72像素宽，完整显示“选择中”，工具区保持单行。
- 有勾选时默认选择“已勾选的消息”，日期默认覆盖全部已选消息；可改为导出日期范围内全部记录。编辑日期后按该范围导出，结束日期包含当天全天。搜索隐藏的勾选仍保留。
- 当前格式下拉框仅提供HTML（含本地图片）；其他格式留待后续开发。点击“开始导出”后选择文件保存位置。
- 日期可输入或通过日历选择；清空、不合法日期和开始晚于结束时在窗口内提示，保留取消及Esc退出。

保留960×640最小窗口、单行工具区、群内消息搜索、细滚动条、多群合并/分开导出和清晰图片等功能。

下载`ChatKeep.exe`后可直接运行，无需安装Python或.NET；附件另含`SHA256SUMS.txt`与`ThirdPartyLicenses.zip`。

已通过消息选择、工具栏、日期与格式菜单等界面检查，以及无外部Python/.NET环境下的独立启动验证。读取与导出组件保持兼容，44项封装模块测试通过。
